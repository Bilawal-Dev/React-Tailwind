# Trend Fusion E-commerce Store (Frontend)

This is the frontend of the Trend Fusion e-commerce store, built using React.js, Tailwind CSS, and Context API. It provides a smooth user experience with functionalities like viewing products, adding items to the cart, searching for products, and more.

## Features
- View products with detailed information
- Add items to the cart and manage cart items
- Product search functionality
- Fully responsive design built with Tailwind CSS
- State management using React Context API for global state management
- Smooth navigation and user interface

## Technologies Used
- **React.js**: JavaScript library for building user interfaces
- **Tailwind CSS**: Utility-first CSS framework for custom, responsive designs
- **Context API**: For managing global state across components
